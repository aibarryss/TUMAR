# Проверка упрощённой навигации

Новая SQL-миграция и новые параметры .env не требуются. Перезапустить Expo через `npm start -- --clear`, открыть проект на Android. Добавлен только стандартный модуль безопасных отступов, поддерживаемый Expo Go.

## Проверить на телефоне

1. После входа видны две нижние вкладки «Главная» и «Контакты». Они не прокручиваются вместе с содержимым и не перекрывают системную навигацию Android.
2. «Аккаунт» открывает отдельное окно поверх затемнённого экрана, показывает email и «Выйти из аккаунта». «Закрыть», нажатие за окном и системная кнопка Back закрывают диалог. При ошибке выхода она видна внутри окна. Проверить выход и восстановление входа после перезапуска.
3. На главной ясно, кому отправится тестовый SOS. Подтверждение перед отправкой сохранено.
4. Входящий сигнал подписан «Сигнал от». На подробностях «Подтвердить просмотр» видно выше карты; отправитель видит только «Завершить тест». После подтверждения понятно, кто просмотрел событие.
5. В контактах два направления: «Кому я отправляю сигналы» и «От кого я получаю сигналы». Поле кода скрыто до «У меня есть код». После создания приглашения выделено «Поделиться кодом».
6. Создать код, перейти на главную и вернуться: код остаётся. После принятия другим аккаунтом повторное открытие контактов обновляет связь и убирает использованный код.
7. При проверке состояния сигнала уйти назад или на другую вкладку, пока запрос ещё выполняется. После его завершения приложение не должно самовольно открыть прежние подробности. В условиях плохой сети не должно блокироваться перемещение между разделами.
8. Проверить открытый код, длинный email, увеличенный системный шрифт и клавиатуру. Кнопки доступны через прокрутку, подписи не обрезаны. Кнопка клавиатуры «Готово» проверяет введённый код, клавиатура закрывается при успешной проверке.
9. TalkBack не читает скрытые контакты на главной; выбранная нижняя вкладка объявляется выбранной. Важные состояния различимы не только цветом.
10. Пройти прежние сценарии: принять код, отправить SOS, подтвердить просмотр, завершить тест и удалить активную связь. Серверная логика не менялась.

Локальные проверки: `npm run typecheck`, `npm test` и Android-экспорт. Они не заменяют перечисленные проверки native UI. Дизайн-промпты для друга: [Stitch](../design/stitch-navigation-prompts.md).

## Сверка с архивом Stitch (3)

Главная, контакты, детали сигнала и окно аккаунта перенесены из соответствующих `tumar_1`, `tumar_3`, `tumar_2` и `tumar_overlay`. Сверить на Android: тёмный фон #0E141B, карточки #161C23, золотые акценты #E9C176 / #C5A059, SOS #93000A, кнопка аккаунта с круглой иконкой, золотая линия над выбранной вкладкой, входящие карточки с золотой левой границей.

Демонстрационные блоки из Stitch показываются только при соответствующем настоящем состоянии. В приложении нет переключателя вымышленной роли, подключённого кулона, SMS и звонков. Длинные email и системный масштаб текста могут менять высоту карточек. Совпадение по пикселям ещё не проверено на физическом телефоне.
