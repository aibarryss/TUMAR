# Настройка и проверка входа

## Подключение

В корне проекта уже создан локальный `.env`. Вставить значения после знака `=`:

- `EXPO_PUBLIC_SUPABASE_URL` — HTTPS Project URL из Supabase.
- `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` — Publishable key, начинающийся с `sb_publishable_`.

Значения вводятся без угловых скобок и без переносов внутри строки. Не использовать Secret key, service_role, пароль базы или ключ аккаунта. `.env` исключён из Git; `.env.example` содержит только имена переменных. Параметры EXPO_PUBLIC встраиваются в приложение и не являются хранилищем секретов.

В Supabase включить Email и Allow new users to sign up. Confirm email временно выключен для тестов команды; это не проверяет принадлежность почты. Собственных таблиц для входа не требуется. Перед внешним пилотом отдельно настроить письма, подтверждение почты и восстановление пароля.

После изменения `.env` остановить Expo через Ctrl+C и выполнить `npm start -- --clear`. Снова открыть проект в Expo Go. Телефон и компьютер должны иметь доступ к интернету; для LAN-запуска они также должны находиться в общей сети.

## Проверка на Android

1. Выбрать «Создать аккаунт», ввести свою тестовую почту и пароль минимум из 8 символов. Нажать «Зарегистрироваться».
2. Ожидать главную TUMAR. Почта аккаунта и выход доступны через «Аккаунт». В Supabase → Authentication → Users должна появиться запись. Если Confirm email включён, немедленного входа не будет: приложение покажет сообщение о необходимости подтверждения.
3. Закрыть и заново открыть проект в Expo Go: вход должен восстановиться без ввода пароля.
4. Нажать «Выйти»: снова отображается форма. Перезапустить проект и убедиться, что сессия не восстановилась.
5. Войти существующим аккаунтом, затем проверить неверный пароль, пустые поля, повторное нажатие во время загрузки и временно отключённый интернет. Ошибка не должна выглядеть как успешный вход.
6. Повторить вход другим тестовым аккаунтом: отображается его почта. Пароль не должен оставаться в форме после успешного входа или смены режима.

Дизайн сохранён. Вход и регистрация используют одну форму. Восстановление пароля пока не подключено; неработающая ссылка убрана. После входа открывается главная с нижними вкладками «Главная» и «Контакты»; email и выход находятся в диалоге «Аккаунт». Для контактов отдельно выполнить [настройку SQL](supabase-contacts.md), для тестовой тревоги — [следующую миграцию](supabase-test-sos.md). Push ещё не подключён.

Сессия хранится локально через AsyncStorage, пароль отдельно не сохраняется. Это стандартное локальное хранилище для текущего Expo Go-прототипа, не зашифрованное хранилище секретов. При восстановлении запускается обновление токена; доступ к будущим данным должен проверяться сервером и правилами базы, а не наличием экрана входа.
