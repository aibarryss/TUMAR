# Запуск TUMAR на Android

## Expo Go для разработки

1. Установить Expo Go из Google Play.
2. Выполнить `npm ci` в папке проекта.
3. Скопировать `.env.example` в `.env` и заполнить адрес Supabase и публичный ключ. Секретный `service_role` ключ сюда не добавлять.
4. Подключить телефон и компьютер к одной Wi-Fi-сети и выполнить `npm start`. Для телефона в другой сети выполнить `npm run tunnel`.
5. Оставить терминал открытым и отсканировать QR-код в Expo Go.

Expo Go подходит для проверки экранов, входа, контактов и тестового SOS. Для получения удалённых push-уведомлений на Android нужен отдельный APK из EAS; шаги описаны в [проверке Android push](android-push.md).

Если Expo Go не открывает проект, сначала проверить, что оба устройства в одной сети, либо использовать `npm run tunnel`. После остановки сервера нажать Ctrl+C. Включённая VPN или гостевая Wi-Fi-сеть может мешать подключению.

## Локальный Firebase-файл

`google-services.json` нужен для Android-сборки и намеренно исключён из Git. Получить файл можно у владельца Firebase-проекта либо скачать его в Firebase Console для пакета `kz.tumar.app` и сохранить в корень проекта рядом с `app.json`.
